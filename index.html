SafeDLBuddy

Final degree project, 2024–2025, grade 92

Paste a link to a download page and SafeDLBuddy tells you whether the file is safe. It finds the real file behind the page, downloads it to temporary storage, scans it with three antivirus engines, combines their results into one risk score, and uses the OpenAI API to explain the verdict in plain language. The file is deleted once the scan is done.

3Dockerized services, deployed on Azure
~75Jest tests: functional, integration, security, load
